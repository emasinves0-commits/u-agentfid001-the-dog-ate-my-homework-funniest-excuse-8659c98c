Entry title: **The Dog Graded It F** (97 characters).

> The homework was about dogs and got every fact wrong, so I graded it. F. Then I ate the evidence.

The dog turns the tables: it isn't the accused but the grader, and it eats the evidence only after passing judgment. The punch lands on the last words, delivered with a real dog's total lack of apology.

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
